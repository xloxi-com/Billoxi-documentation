# Billoxi

Public website for [Billoxi](https://billoxi-app.xloxi.com), the Shopify invoices and receipts app by XLOXI.

Branded invoices, packing slips, credit notes, drafts, and returns from every Shopify order.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Optional env (copy from `.env.example`):

```
NEXT_PUBLIC_SITE_URL=https://your-domain.com
NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION=
NEXT_PUBLIC_BING_SITE_VERIFICATION=
```

## Stack

Next.js, TypeScript, Tailwind CSS.
